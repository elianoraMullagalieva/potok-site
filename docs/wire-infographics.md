# Проволочная инфографика «Поток»

Генеративные объекты из линий и точек, рисуются на canvas без картинок и WebGL.
Компоненты: `src/ui/Wire.tsx` и `src/ui/Curves.tsx`. Используются в выгодах V2 и могут стоять в любой карточке.

## `<Wire kind=… />`
| kind | Что это | Где уместно |
|---|---|---|
| `funnel` | воронка из колец, нижнее кольцо акцентное | Директ, трафик → заявки |
| `coil` | стопка колец, поток | скорость, конвейер |
| `wave` | прозрачная сетка-волна, бегущая подсвеченная ячейка | CRM, прозрачность, данные |
| `poly` | икосаэдр с дугами, сигнал бежит по рёбрам | связки, сеть, антифрод |
| `rings` | три переплетённых кольца | команда из троих |
| `dots` | сфера из 1100 штрихов, доля `faded` подсвечена | «9 из 10», доли и проценты |

Параметры: `color` (линии), `accent` (жёлтый акцент), `stroke` (толщина), `speed` (скорость), `faded` (доля для `dots`).
Рисует только когда виден (IntersectionObserver), при `prefers-reduced-motion` один статичный кадр.

## `<Curves />`
Семейство S-кривых на сетке с бегущей точкой по акцентной кривой. Рост бюджета, прогноз, «от … до».

## Правила
- Один акцентный цвет на объект, остальное ink.
- Толщина линии 0.9–1.4 px, объект не крупнее 60 % карточки.
- Анимация в карточках кольца идёт только в резкой зоне (`[data-live]`), см. `SkyRing.tsx`.
